# Cryptoistic HFT Bot
High-frequency crypto day trading bot with hacker-style dashboard. Run in GitHub Codespaces.

**Instructions:**
1. Open in GitHub Codespaces.
2. Wait for post-create commands to install dependencies.
3. Start client: `cd client && npm start`
4. Access dashboard: `http://localhost:3000`
5. Backend API runs on `http://localhost:8000`

**Note:** Demo mode uses mocked prices for testing. Replace `fetch_price` with real exchange API calls to trade live.
